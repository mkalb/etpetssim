# Security Policy

## Supported Versions

Only the latest release receives security fixes. Older releases and pre-releases are not supported; update to the
latest release first.

## Reporting a Vulnerability

Do not report security vulnerabilities in public issues, pull requests, or comments.

Report them privately via [private vulnerability reporting](https://github.com/mkalb/etpetssim/security/advisories/new)
on GitHub (tab "Security", button "Report a vulnerability"). Describe the vulnerability, the affected version, and the
steps to reproduce it.

The project is maintained by a single developer, so responses may take some time. The maintainer assesses the report
and, if it is confirmed, fixes it in a new release and publishes a security advisory.
